# Smart Grid

A smart grid is an electricity network that uses digital communication, sensors, and automation to monitor and manage the flow of power in real time. It is the connective tissue between renewable generation and modern consumption.

## Core Capabilities
- Two-way communication between utilities and consumers.
- Real-time sensing via [[IoT Sensors]] and smart meters.
- Automated fault detection and self-healing.
- Demand response and dynamic pricing.

## Why It Matters
Traditional grids were designed for one-way flow from large centralized plants. High penetration of distributed [[Solar Photovoltaics]] and [[Wind Power]] requires a grid that can balance many small, variable sources. The smart grid is therefore a prerequisite for the renewable transition.

## Urban Dimension
In cities, the smart grid integrates with [[Smart Buildings]], [[Smart Street Lighting]], and electric-vehicle charging through [[Smart Mobility]]. It is a foundational layer of the [[Smart City Overview]].
