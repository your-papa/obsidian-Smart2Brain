# Machine Learning Basics

#technology #ai

Machine learning is a subset of artificial intelligence that enables systems to learn and improve from experience without being explicitly programmed. It focuses on developing algorithms that can access data and use it to learn for themselves.

## Supervised Learning

In supervised learning, the algorithm learns from labeled training data. Common techniques include:

- **Linear regression** for predicting continuous values
- **Classification** using decision trees or support vector machines
- **Neural networks** for complex pattern recognition

See also: [[Neural Networks Deep Dive]]

## Unsupervised Learning

Unsupervised learning finds hidden patterns in data without labeled responses. Clustering algorithms like k-means group similar data points together, while dimensionality reduction techniques like PCA simplify high-dimensional datasets.

## Applications

Machine learning powers recommendation engines, fraud detection, natural language processing, and autonomous vehicles. The field continues to evolve rapidly with advances in deep learning and transformer architectures.
