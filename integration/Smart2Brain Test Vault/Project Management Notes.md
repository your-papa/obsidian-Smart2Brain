# Project Management Notes

#productivity #management

Effective project management balances scope, time, and resources while keeping stakeholders aligned. These notes capture key methodologies and lessons learned.

## Agile Methodology

Agile emphasizes iterative development, continuous feedback, and adaptive planning. Scrum and Kanban are the most widely adopted frameworks.

### Scrum Essentials

- **Sprint planning** — selecting work items for a 2-week iteration
- **Daily standups** — brief 15-minute check-ins on progress and blockers
- **Sprint review** — demonstrating completed work to stakeholders
- **Retrospectives** — reflecting on process improvements

## Technical Debt

Technical debt accumulates when teams prioritize speed over code quality. Like financial debt, it compounds over time. Regular refactoring sprints and code review practices help keep it manageable.

## Documentation Strategy

Good documentation lives close to the code and stays updated through automation. Use README files for project setup, architecture decision records (ADRs) for design choices, and inline comments only for non-obvious logic.

## Remote Team Coordination

Distributed teams need asynchronous communication norms, shared tooling for [[Obsidian Plugin Development|knowledge management]], and overlapping work hours for synchronous collaboration. Tools like Obsidian and shared wikis help maintain a single source of truth.
